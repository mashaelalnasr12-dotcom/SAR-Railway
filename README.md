### Connecting the Java System to the Database

1. Open MySQL Workbench and connect to your local MySQL instance.
2. Run all the provided SQL database files in the correct order to create and initialize the database.
3. Open `DatabaseAndUI.java` and update the database password to match your local MySQL password.

**Note:** Each team member must use their own local MySQL password.

**Note:** don't commit your actual MySQL password to GitHub
